# Munjanne Coffee Website

Files:
- index.html — complete responsive website
- robots.txt — crawler instructions
- sitemap.xml — Google sitemap

IMPORTANT:
1. Replace YOUR_WHATSAPP_NUMBER in index.html with the business WhatsApp number, including country code.
2. Replace https://www.munjannekapi.in/ with the final domain if you choose a different domain.
3. Upload all files to your hosting.
4. Verify the domain in Google Search Console and submit sitemap.xml.

The design is mobile-first and uses the Munjanne cream/brown/gold/green visual style.
